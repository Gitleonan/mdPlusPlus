## Design Specificity(设计专属性)

**总体判定:大部分是为 md++ 而作的真设计。** token 层有宣言式哲学(Soft Structuralism)、全站复用单一运动曲线 [0.32,0.72,0,1]、监听指示器(呼吸光点+涟漪+±统计)完全定制——毛玻璃承诺是真 token 而非表面装饰;plume 式排版在宣传图中得到印证。**可互换的部分是标题栏**:8 个匿名图标按钮放进任何 Electron 阅读器都成立,chrome 里没有任何东西说「这是 md++」;内置主题体系这一差异化卖点被一个标签错误的 Palette 图标埋没。

**浏览器覆盖层**:注入技术成功,但页面在纯浏览器崩溃——2 条控制台发现(pre 溢出 108px、#dc2626 对比度 3.6:1)全部指向崩溃兜底页,属环境伪影,不计入 UI 问题。

## Overall Impression

内容舞台和监听模式是被真正设计过的;标题栏信息架构和错误面是欠账。最大机会:把「监听」这面旗舰从 8 个匿名图标里抬出来,同时堵住两处静默数据丢失——这两件事做完,这个应用的气质就从「工具」变成「作品」。

## What's Working

1. **监听模式指示器系统**——状态胶囊、呼吸光点、±n 统计、逐条导航、危险色退出。产品的差异化承诺「变化可见」得到了全应用最完成的 UI,原则与像素真正一致。
2. **编辑器保存编排**——● 未保存 → 保存中… → 已保存 ✓ 三态,加上 EOL/BOM 还原这类高信任细节。
3. **一致的 token + 运动语言**——单一缓动曲线、全局模糊淡入、命名的 radius/shadow/glass 刻度,prose.css 消费规范。

## Priority Issues

**[P1] 静默丢失用户修改。** 退出编辑(Editor.tsx:226)与关闭 tab 都无视 isDirty;保存失败只进 console。用户改了半天点错一下,全没了——对「临时看一眼顺手改两笔」的核心场景是致命的。
**修**:两条路径加 isDirty 守卫(confirm 或保留草稿);保存失败出 toast。
**建议命令**:/impeccable harden

**[P1] 开发者错误面直接给用户。** 全屏红字堆栈(实测确认——纯浏览器里这是唯一能渲染的东西);编辑模式 Ctrl+P 静默无响应;主题导入坏 CSS 静默无效果。「双击即开」承诺的 2 秒降级故事今天是零。
**修**:ErrorBoundary 换人话 + 重试;堆栈进 console;IPC 缺失时降级只读模式;导出禁用给行内提示。
**建议命令**:/impeccable harden

**[P1] 标题栏过载。** 9 个并列控件(打开 + 8 工具),6 个无标签,零分组——文档操作(监听/编辑/刷新/导出)、视图模式(Zen)、系统项(主题/调色/无痕/关于)挤成一排相同的 28px 方块。认知负荷检查表两项失败(选项数、分组)。
**修**:文档组与系统组视觉分隔;Palette/Ghost/Info 收进溢出菜单;或监听按钮常驻文字标签、其余降级。
**建议命令**:/impeccable distill(收进菜单)+ /impeccable layout(分组分隔)

**[P2] 暗色模式 token 泄漏。** .monitoring-btn-danger(themes.css:1558-1571)只有浅色配色且无暗色覆盖——暗色玻璃里出现一块刺眼的浅色胶囊;两种成功绿并存;~38 处裸 hex。
**修**:建立 --success/--danger token 族(明暗双套)并迁移。与 extract 勘察结论相同。
**建议命令**:/impeccable colorize

**[P2] 弹窗方言分裂。** ExportPdfModal 有 role/aria-modal/Esc/焦点管理;About/ThemeManager 什么都没有(屏幕阅读器收不到对话框通告);删除确认用原生 confirm() 打破玻璃语境。
**修**:抽共享 Modal 外壳(与 extract 计划一致,一石二鸟)。
**建议命令**:/impeccable audit 后接共享组件提取
